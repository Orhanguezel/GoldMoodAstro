# İçerik Format Sınıflandırması

## İçerik tipleri

- `single-image`: Tek görsel post
- `carousel`: Çoklu görsel post
- `reel`: Video / reel
- `story`: Hikâye
- `profile`: Profil/bio analizi
- `live`: Canlı yayın duyurusu

## Format etiketleri

- `hook-question`: Başlık soru ile açılır.
- `pick-a-card`: Kullanıcı 1/2/3 seçer.
- `zodiac-list`: Burç burç kısa yorum.
- `symptom-list`: “Bunu yaşıyorsan…” formatı.
- `saveable-guide`: Kaydedilecek mini rehber.
- `myth-vs-truth`: Yanlış bilinenler.
- `before-after`: Önce/sonra farkındalık.
- `consultant-cta`: Danışmana yönlendirme.
- `comment-trigger`: Yorum yazdıran format.
- `share-trigger`: Arkadaşına gönder formatı.

## Performans okumada dikkat

Beğeni tek başına yeterli değil. Özellikle bizim alanımızda şu sinyaller daha değerlidir:

- Yorum: konu insanı harekete geçiriyor mu?
- Kaydetme: içerik rehber/değer taşıyor mu?
- Paylaşım: “bunu birine göndermeliyim” etkisi var mı?
- Profil tıklaması: danışmanlık/üyelik yoluna taşıyor mu?
- Link tıklaması: gerçek dönüşüm potansiyeli var mı?
