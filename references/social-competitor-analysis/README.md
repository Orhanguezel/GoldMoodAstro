# Sosyal Medya Rakip / Sektör Analizi

Amaç: Astroloji, tarot, numeroloji, kahve falı, rüya tabiri ve spiritüel danışmanlık alanında sektörde hangi içerik formatlarının çalıştığını görmek; bunları GoldMoodAstro çizgisine özgün şekilde uyarlamak.

Bu klasör telifli görselleri birebir yeniden kullanmak için değil, kaynaklı referans ve format analizi için tutulur.

## Kullanım

1. `accounts.csv` içine analiz edilecek hesapları ekle.
2. Her hesap için iyi performanslı gönderileri `posts.csv` içine gir.
3. İçerikleri `format-taxonomy.md` sınıflarına göre etiketle.
4. Sonuçları `goldmood-adaptation.md` ile GoldMood içerik fikirlerine dönüştür.
5. Aylık paylaşım ritmi için `goldmood-monthly-content-strategy.md` şablonunu kullan.

## Önerilen metrikler

- Beğeni
- Yorum
- Görüntülenme / reel izlenme
- Kaydetme, varsa
- Paylaşım, varsa
- İçerik tipi
- Görsel format
- Hook / ilk cümle
- CTA
- Konu
- Yorumlarda tekrar eden sorular

## Not

Instagram public verisi bazen login/cookie olmadan tam alınamıyor. Eğer hesap postlarını topluca analiz edeceğiz diyorsak en sağlıklı yol:

- Instagram’dan manuel CSV/export,
- ya da yetkili erişim/cookie ile sadece analiz amaçlı metadata çekimi,
- ya da ekran görüntüsü + link + metrikleri manuel girme.
